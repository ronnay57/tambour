# Direction visuelle et sonore

## Intention

Donner l'impression de jouer sur un vrai instrument : matières (peau tendue, bois, métal), réaction immédiate à chaque frappe, et une interface qui s'efface pendant le jeu.

## Visuel

- **Vue de dessus du kit** : chaque pièce est une zone de frappe ronde, assez grande pour le doigt (au moins 64 px).
- **Retour de frappe** : onde qui part du point d'impact, légère compression de la peau, intensité selon la vélocité.
- **Palette** : tons naturels (peau crème, bois, laiton) avec un thème sombre « scène » pour jouer le soir.
- **Typographie** : une police affirmée pour le titre, une police lisible pour les commandes.
- **Accessibilité** : contrastes suffisants, touches clavier affichées sur chaque pièce, animations réduites si l'utilisateur le demande.
- **Mobile d'abord** : le kit tient sur un écran de téléphone en paysage comme en portrait.

## Son

- Plusieurs échantillons par pièce (vélocités, variations) pour éviter l'effet « mitraillette ».
- Légère réverbération commune pour unifier le kit.
- Boucles d'accompagnement calées sur le tempo choisi, dans quelques ambiances (groove, afro, lo-fi, électro).
- Volume général et volume des boucles réglables séparément.
